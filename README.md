# TapeHead

Efecto de la familia **Sampled Head**: el previo de una consola de multipista de casete de los 80–90 usado como
saturador (de grosor cálido a overdrive arenoso y fuzz aplastado), sin artefactos de cinta.

- **Plugin** VST3 / AU / Standalone para Windows y Mac (`vst/`) — descargas en [Releases](../../releases).
- **Dentro de Tono-Pad** como efecto de los pads (mismo motor: `dsp/tapehead.js`).
- Diseño: `design/preview.html` (interfaz web reutilizable en `web/th-ui.js`).

Detalles, decisiones y límites en [HOJA_DE_PROYECTO.md](HOJA_DE_PROYECTO.md).
